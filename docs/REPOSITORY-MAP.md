# Repository Map

A curated map of the public work connected to this profile.

## Core engineering

### [Windows IT Toolkit / SchunkOps](https://github.com/dschunk/windows-it-toolkit)

**Audience:** help desk, Windows sysadmins, AD engineers, infrastructure engineers, incident responders, instructors.

Read-only-first PowerShell diagnostics and evidence tooling across Windows endpoints, Windows Server, AD, Kerberos, GPO, DNS/DHCP, certificates, clusters, vSphere, and incident response.

Start with: [Quick Start](https://github.com/dschunk/windows-it-toolkit/blob/main/docs/QUICKSTART.md)

### [SchunkOps Microsoft 365](https://github.com/dschunk/microsoft-365-ops)

**Audience:** Microsoft 365 support, Entra admins, Exchange admins, security teams, instructors.

Twenty read-only PowerShell tools for identities, licensing, sign-ins, service health, mailbox support, privileged access, forwarding, transport rules, Conditional Access, guests, Teams, and tenant evidence.

Start with: [Help Desk Guide](https://github.com/dschunk/microsoft-365-ops/blob/main/docs/HELPDESK.md)

### [Build It Like You Won't Be There Tomorrow](https://github.com/dschunk/build-it-like-you-wont-be-there)

**Audience:** engineers, team leads, instructors, managers.

Reusable runbook, handoff, change, recovery, access-review, backup, monitoring, post-incident, and decommissioning templates.

Start with: [System Runbook](https://github.com/dschunk/build-it-like-you-wont-be-there/blob/main/templates/system-runbook.md)

### [Infrastructure Dashboard](https://github.com/dschunk/infrastructure-dashboard)

**Audience:** infrastructure engineers, UI/operations designers, instructors.

A public operations-interface case study built with synthetic telemetry. Demonstrates status semantics, degraded-state communication, accessibility, audit concepts, and safe presentation of operational data.

### [FiveM Server Ops](https://github.com/dschunk/fivem-server-ops)

**Audience:** Windows game-server operators, homelab users, PowerShell learners.

A specialized example of applying ordinary infrastructure discipline—monitoring, validated backups, configuration review, logging, inventory, and visible failure—to FiveM servers.
